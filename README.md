# IFCD093PO · Machine Learning aplicado usando Python · Recursos del libro

Material complementario del libro para la especialidad formativa IFCD093PO. Cada código QR
del libro lleva a uno de estos recursos:

- **Ejecuta**: cuadernos que se abren en el navegador (JupyterLite), sin instalar nada.
- **Explora**: herramientas interactivas.
- **Compruébalo**: tests de autoevaluación.

La tabla `recursos.csv` es la fuente única: `herramientas/construir.py` genera la web y el
bloque de recursos del libro.

Web publicada: <https://especialidades-formativas.github.io/ifcd093po/>
